# MangaNest — комплект лабораторных работ

Учебный проект каталога манги для **Кадылгожа Расула**, группа **24-ИС-1**. Папка подготовлена отдельно для передачи одногруппнику. В ней намеренно нет `.git` и нет публикации в GitHub — репозиторий и отправку работ Расул настроит самостоятельно.

## Структура

- `labs/lab1/` — три семантические HTML-страницы без CSS;
- `labs/lab2/` — те же экраны с токенами и адаптивным оформлением;
- `labs/lab3/` — каталог на чистом JavaScript с локальными данными и списком для чтения;
- `labs/lab4/` — каталог и страница серии с Open Library API;
- корень проекта (`src/`) — итоговое React + TypeScript SPA для лабораторных 5–6;
- `docs/labN/labN.md` — отчёты с именем и группой Расула.

Обложки MangaNest находятся в `assets/covers/`. Учебный каталог из 40 серий — в `data/books.js`.

## Запуск лабораторных 1–4

Откройте папку проекта в редакторе и запустите локальный статический сервер. Например, если Python доступен:

```powershell
py -m http.server 8000
```

Затем откройте соответствующий адрес:

- `http://localhost:8000/labs/lab1/`;
- `http://localhost:8000/labs/lab2/`;
- `http://localhost:8000/labs/lab3/`;
- `http://localhost:8000/labs/lab4/`.

Для браузерных модулей и API нужен локальный сервер; двойной щелчок по HTML может заблокировать JavaScript-модули. Если `py` не установлен, используйте `python -m http.server 8000` или Live Server в редакторе.

## Запуск лабораторных 5–6

Нужен Node.js версии не ниже 22.22:

```powershell
npm install
npm run dev
```

Проверки, которые можно выполнить локально:

```powershell
npm test
npm run lint
npm run build
```

## Отчёты и снимки

В отчётах не вписаны фиктивные результаты W3C, Lighthouse, сборки, Postman или браузерных сценариев. Пункты, требующие установленного браузера/Node.js или внешнего сервиса, отмечены к выполнению. После проверки сохраняйте фактические скриншоты и результаты в соответствующей папке `docs/labN/`.

Имя и группа указаны в отчётах; даты нет. Перед сдачей Расулу нужно самостоятельно выполнить проверки, добавить свои скриншоты/выводы и при необходимости перенести папку в созданный им GitHub-репозиторий.
