# Как Расулу подготовить GitHub для сдачи

Эта папка передаётся без `.git`: историю и репозиторий создаёт сам студент в своём аккаунте.

1. Создать новый пустой репозиторий на GitHub и скопировать его HTTPS-адрес.
2. Открыть терминал в папке `Rasul_MangaNest`, выполнить `git init`, затем `git switch -c lab-1/markup`.
3. Проверить `git status`, добавить файлы и сделать несколько небольших осмысленных коммитов (например: каркас HTML, содержимое экранов, стили и документация).
4. Подключить свой remote командой `git remote add origin <адрес>` и отправить ветку: `git push -u origin lab-1/markup`.
5. Открыть GitHub и создать Pull Request из `lab-1/markup` в основную ветку. Ссылку на PR добавить в отчёт.

Не копируйте в репозиторий чужую папку `.git` и не добавляйте личные токены/пароли.
