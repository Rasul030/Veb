### Цель работы

Перенести интерфейс каталога на React + Vite + TypeScript, разделить его на переиспользуемые компоненты и описать типы данных.

### Выполненная работа

Корневая версия проекта использует React, TypeScript и Vite. Страницы и композиция находятся в `src/app/` и `src/pages/`; повторно используемые компоненты каталога, списка и карточек расположены в `src/features/` и `src/shared/`. API-запросы отделены от UI, а хуки отвечают за загрузку, задержку поиска и список для чтения. Общие CSS-токены повторно используются из лабораторной 2. Структура компонентов и владельцы состояния описаны в `docs/lab5/components.md`.
