## Маршруты, состояние и формы MangaNest

**Студент:** Кадылгожа Расул  
**Группа:** 24-ИС-1

### Цель работы

Добавить маршрутизацию, разделяемое состояние и проверяемые формы в приложение MangaNest.

### Выполненная работа

React Router описывает каталог, сведения о серии, создание/редактирование записи, список для чтения, вход и страницу 404 в `src/app/App.tsx`. `AppLayout` содержит общую шапку, переключение темы сохраняется в `localStorage`, а демонстрационный вход хранится в контексте и закрывает список для чтения через `RequireAuth`. Параметры поиска, темы, сортировки, доступности и номера страницы синхронизируются с URL.

Форма создания и редактирования использует React Hook Form и схему Zod из `src/shared/validation/bookSchema.ts`, включая проверку связи годов публикации. Для CRUD используется локальная API-заглушка с ветками обработки 422, 409 и общей серверной ошибки; серверная аутентификация в учебный проект не включена.
