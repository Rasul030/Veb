**Студент:** Кадылгожа Расул  
**Группа:** 24-ИС-1

### Цель работы

Стилизовать экраны mobile-first и объединить их общей системой дизайн-токенов со светлой и тёмной темами.

### Выполненная работа

Страницы предыдущей работы скопированы в `labs/lab2/` и подключают общие таблицы стилей из `styles/`:

- `tokens.css` задаёт палитру MangaNest, отступы, радиусы, типографику, тени и размеры;
- `base.css` задаёт базовый поток, сброс, типографику и видимый `:focus-visible`;
- `layout.css` использует Flexbox для шапки и Grid с `auto-fit`/`minmax` для каталога;
- `components.css` оформляет карточки, формы, ссылки, кнопки, состояния полей и сообщения.

Тёмная палитра выбирается через `prefers-color-scheme` и может быть переопределена атрибутом темы. Для уменьшения движения отдельные переходы и анимации не используются. Дополнительные компоненты продолжают использовать общие токены.

### Контроль адаптивности

| Ширина | Ожидаемое поведение | Фактическая проверка |
| ---: | --- | --- |
| 320 px | Нет горизонтальной прокрутки | Ожидает проверки в браузере |
| 375 px | Одна колонка | Ожидает проверки в браузере |
| 768 px | Переносимая навигация и две колонки по доступной ширине | Ожидает проверки в браузере |
| 1440 px | Каталог в несколько колонок и фильтры сбоку | Ожидает проверки в браузере |

Скриншоты контрольных размеров в светлой и тёмной темах следует сохранить сюда под именами `viewport-<ширина>-<тема>.png` (шесть файлов). Таблица Lighthouse остаётся незаполненной до запуска браузерного аудита.
