### Цель работы

Реализовать интерактивный клиентский каталог, разделив данные, чистую логику фильтрации и работу с DOM.

### Выполненная работа

В `data/books.js` находится учебный каталог из 40 серий по пяти жанрам. `lib/books.js` содержит функции поиска по названию/автору, комбинированной фильтрации, сортировки и получения сохранённого списка. Интерактивная страница демонстрации расположена в `labs/lab3/`: её `main.js` обновляет карточки через DOM API, обрабатывает фильтры и делегирует действия по списку для чтения. Идентификаторы сохранённых серий хранятся в `localStorage` с обработкой недоступного хранилища.

Для логики добавлены тесты `tests/books.test.js`; команда запуска описана в `package.json` как `npm test`.
