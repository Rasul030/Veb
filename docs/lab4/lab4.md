# Отчёт по лабораторной работе № 4

## Работа с Open Library API в MangaNest

**Студент:** Кадылгожа Расул  
**Группа:** 24-ИС-1

### Цель работы

Подключить каталог к REST API и обработать загрузку, пустую выдачу, ошибки и отмену устаревших запросов.

### Выполненная работа

API-версия каталога находится в `labs/lab4/`. Запросы разделены на `api/client.js` и `api/books.js`: базовый клиент собирает query-параметры, передаёт `AbortSignal`, проверяет HTTP-статус и декодирует JSON; API-слой нормализует поиск и карточку произведения Open Library. `main.js` выполняет поиск с задержкой, отменяет устаревший запрос, показывает состояние загрузки/пустой результат/ошибку, поддерживает пагинацию и сохраняет список для чтения. Подробная страница загружает запись по ID.

Коллекция Postman подготовлена в `docs/lab4/api-collection.json`.
